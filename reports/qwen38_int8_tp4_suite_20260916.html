Conclusions

  1. DFlash2 spec decode is the decode lifeline. INT8 TP4 no-spec 75 tok/s → with spec 272 tok/s (3.5×). The no-spec INT8 4-card config is dead.
  2. P2P is the prefill lifeline. TP4 with P2P off: prefill 1k 2,931 → 830 tok/s (3.5× gap). A P2P loss (Xid120 / GSP) is a disaster.
  3. Production vs 2-card baseline: single-stream decode is a wash (272 vs 275 numeric), prefill 1.5× (2,765 vs 1,882), n8 aggregate a wash (714 vs 706). The cost of 4-card + INT8 + spec: decode does not get faster; what you buy is 262K ctx + 753K KV + 1.5× prefill.
  4. The symm flag is a no-op on 3090 (sm_86). SymmMemCommunicator does not support Ampere; symm vs non-symm is within noise.
  5. INT4 4-card lanes are dead. No-spec 4-card (TP2×PP2 / TP4) decodes at 74–99 tok/s, far below INT8 + spec; INT4 + spec leads INT8 by only +10–17% on decode (see decision below).

INT4 vs INT8 decision: INT4 TP4+DFlash is faster on both sides but by a small margin (decode +10–17% / prefill +6%). W4A16 loops/repeats on long-context, multi-turn agent and tool-call workloads — the failure cost far exceeds +10% tok/s. Default stays INT8 + DFlash2. The value of 4 cards is prefill (~1.5×, near-linear) + 753K KV + 262K ctx + concurrency, not 2× single-stream decode (single-stream TP2→TP4 is only 1.09–1.41× — the PCIe allreduce latency wall, a physical limit, not a config issue).
